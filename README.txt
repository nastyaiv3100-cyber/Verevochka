ВЁРОВОЧКИ — ЧТО ЕСТЬ ЧТО

1) index.html — РЕДАКТОР
Это главный файл, который открывает страницу редактора.
На GitHub Pages его обязательно оставьте с именем index.html.

2) game-engine.html — ДВИЖОК ИГРЫ
Общий движок, который редактор использует для запуска игр и создания iframe.
Оставьте ему имя game-engine.html и загрузите в ту же папку, что index.html.

3) assets/ — ИЗОБРАЖЕНИЯ ИГРЫ
Загрузите папку целиком рядом с HTML-файлами. Не переименовывайте файлы внутри неё.

Загрузка на GitHub Pages:
- загрузите index.html, game-engine.html и папку assets в корень репозитория, сохранив структуру;
- включите Settings → Pages → Deploy from a branch → main → /(root);
- откройте опубликованный адрес редактора.

Редактор, движок и папка assets работают вместе. Изображения хранятся отдельными файлами, а штатные звуки остаются встроенными в base64. Дополнительные картинки можно загружать файлами или добавлять прямыми HTTPS-ссылками; свои звуки — загружать файлами.

Формулы LaTeX в вопросах отображаются через MathJax; для их визуального оформления нужна связь с интернетом.

Экспорт в Genially:
- откройте редактор с опубликованного HTTPS-сайта и перейдите в «Genially / HTML»;
- загруженные картинки, включая сжатые WebP, сохраняются в коде iframe вместе с настройками игры;
- скопируйте iframe и вставьте его в Genially; ссылка содержит всё необходимое для выбранных вложений, поэтому игра не зависит от файлов на вашем компьютере;
- код автоматически сжимается. Лимит редактора для ссылки — 1 МБ; если он превышен, нажмите «Облегчить код», уменьшите звуки, используйте прямые HTTPS-ссылки или скачайте HTML.

Кнопка «Облегчить код»:
- доступна вверху редактора и в разделе «Genially / HTML»;
- уменьшает крупные загруженные картинки до 1280×720, сохраняя пропорции, и переводит их в WebP с сохранением прозрачности;
- показывает размер кода до и после обработки и обновляет предпросмотр, JSON, HTML и iframe;
- оставляет исходники, если размер кода не уменьшается; анимация, векторные изображения, звуки и картинки по ссылкам сохраняются;
- кнопка «Вернуть исходные картинки» отменяет сжатие картинок в текущем проекте и сохраняет картинки, которые вы успели заменить после него. Загрузка другого JSON-проекта очищает эту отмену.
