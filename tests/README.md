# Проверка экспорта Genially

Из корня репозитория:

```sh
python -m unittest discover -s tests -v
```

Нужны Python с установленным `playwright` и Chromium. Тесты автоматически используют системный `chromium`, если он установлен, иначе браузер Playwright. При необходимости путь можно указать переменной `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.

Проверяются загрузка настоящих WebP и WAV через редактор, iframe длиннее старого ограничения в 7000 знаков, отображение картинок и воспроизведение загруженного звука в игре, победа и проигрыш, gzip и несжатый резервный формат, совместимость старых ссылок, Unicode и восстановление экспорта после превышения допустимого размера.

Файлы сайта подаются в Chromium через перехват запросов на `https://verevochka.test`; сервер, доступ к сети и изменение доверенных сертификатов не требуются. Запросы к необязательным внешним шрифтам и MathJax блокируются.

`test_lighten_code.py` проверяет обе кнопки «Облегчить код»: уменьшение настоящих PNG/JPEG/WebP и сжатого payload Genially, ограничение размеров 1280×720 без увеличения маленьких картинок, сохранение прозрачности и всех типов вложений. Оптимизированные картинки проверяются в предпросмотре и запущенном iframe игры. Также проверяются повторное нажатие без дальнейшего ухудшения картинок, отмена нескольких успешных проходов сжатия, отмена после смены типа вопроса и применения быстрого редактора, сохранение более поздней загрузки, сброс отмены при импорте настроек, анимации PNG/WebP, GIF/SVG и повреждённые изображения. Фикстуры создаются в браузере и стандартными средствами Python без дополнительных библиотек и файлов изображений.

Проверки исправлений редактора:

- `test_editor_state.py`: автосохранение и восстановление картинок, настроек и незавершённых вопросов; ручная JSON-копия, частичный и некорректный импорт, очистка картинок предыдущего проекта, сброс, недоступное хранилище, общая отмена/повтор, сжатие в истории, доступный код и честное сообщение о копировании.
- `test_question_editor.py`: десятичная запятая, альтернативные ответы и пропуски, переключение режимов без потери текста, картинки при перестановке вопросов, неоднозначное соответствие, полный список вариантов, незавершённый JSON и Unicode-пунктуация.
- `test_gameplay_mobile.py`: победа с одним вопросом и повтор игры, доступность длинных титульных и итоговых окон на телефоне, ширина редактора и запуск предпросмотра, доступность кнопок предпросмотра под верхней панелью при прокрутке, одинаковое название черновика в HTML и Genially.

Редактор загружает `editor-state.js` из корня сайта; фикстуры подают этот файл вместе с HTML. Автосохранение изолировано новым браузерным контекстом для каждого теста.
